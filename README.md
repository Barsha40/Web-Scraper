
# Web Scraper

## Description
A Python-based web scraper that extracts headlines
from a public website and saves them into a CSV file.

## Features
- Fetches webpage content
- Extracts headlines using BeautifulSoup
- Checks robots.txt permissions
- Uses a delay between requests
- Saves headlines into CSV format
- Handles network errors

## Technologies Used
- Python
- Requests
- BeautifulSoup4
- CSV Module

## Installation

Install dependencies:

pip install -r requirements.txt

## How to Run

python scraper.py

## Output

The scraped headlines are saved in headlines.csv.
